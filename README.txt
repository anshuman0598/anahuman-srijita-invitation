WEDDING INVITATION — ANAHUMAN & SRIJITA

Files:
- index.html        Main invitation website
- venue-qr.png      Supplied venue QR

The invitation is self-contained and mobile-friendly. Open index.html locally to preview it.

TO MAKE IT ACCESSIBLE ANYWHERE:
1. Upload both files to a static website host such as GitHub Pages, Netlify, or Vercel.
2. The resulting public URL can then be shared or converted into a QR code.
3. The QR inside the invitation is the supplied VENUE QR and opens the venue location.
